# 强化学习的数学基础：学习笔记版

> 本仓库是对 *Mathematical Foundations of Reinforcement Learning* 的中文学习笔记、公式导读与理解辅助，不是官方中文版，也不以逐章全文翻译为目标。

## 仓库定位

- 面向读者：想系统学习强化学习数学基础、但希望先抓住主线和公式意义的读者。
- 内容形式：章节式学习笔记，保留核心结构、关键公式、算法伪代码与简明解释。
- 使用方式：建议将本仓库与英文原书、上游仓库和 Springer 正式出版版本对照阅读。

相关说明：

- 上游来源见 [NOTICE.md](NOTICE.md)
- 版权与使用边界见 [COPYRIGHT.md](COPYRIGHT.md)

### 如果你已经有机器学习基础

### 使用建议

- 先看“学习目标”和“本节要点”，再看公式。
- 看公式时，优先理解“它在算什么”，再看“它是怎么推出来的”。
- 笔记中的白话解释适合建立直觉；严格推导仍建议回看英文原书。
